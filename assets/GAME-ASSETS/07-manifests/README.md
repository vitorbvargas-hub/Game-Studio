# 07-manifests

Schemas JSON e manifests agregados.

- **`creature.schema.json`** — schema de `creature.json` (um por criatura, dentro de
  `01-creatures/CREATURE-NNNN/`). Consumido pelo game-dev no visualizador de sprites
  (briefing §10) e pelo game-qa na homologação (`ASSET_QA_CHECKLIST.md`).
- Manifests agregados futuros (ex. `catalog.json` listando todas as `CREATURE-NNNN` com
  status/score, para o visualizador não precisar varrer o filesystem) entram aqui quando
  o game-dev precisar deles — não criados nesta entrega.
