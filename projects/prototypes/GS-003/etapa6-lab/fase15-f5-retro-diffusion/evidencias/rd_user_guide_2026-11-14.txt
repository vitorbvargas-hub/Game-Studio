01 The 60-second version
This is the whole workflow, condensed. Every step links to a section with the full details.

- Pick a model.On the [Home](https://retrodiffusion.ai/app) page, choose from the Model panel on the left. RD Core is the default: near-RD Pro quality at $0.10 per image, up to 512 px, about 4x faster than RD Pro. RD Pro is the highest quality, RD Fast is the quickest and cheapest, and RD Mini specializes in tiny, low-resolution art. The Advanced Animations and Tilesets tabs live in the same panel.
- Pick an art style.Each model has its own set of styles in the Art Styles panel — Default, Painterly, Isometric, Top Down, and so on. Click a style to see its description, and use View Examples to preview what it produces.
- Describe what you want.Write a prompt about the subject — the style is already handled by your model and style choice. Be specific about details, colors, and setting. Stuck? The sparkle button expands a short idea into a detailed prompt.
- Set size and count, then Generate.Pick your canvas size in pixels and how many images to make. The exact price always shows on the Generate button before you commit — no surprises.
- Refine your results.Results appear on the canvas and in your History on the right. Use the editing tools next to the canvas to inpaint, expand, remove backgrounds, reduce colors, or make textures tile. Pin favorites, download as PNG, or drag any result back in as an input image.
- Go further.Build your own custom style from reference images in [My Styles](https://retrodiffusion.ai/app/my-styles), or grab an API key from [Developer Tools](https://retrodiffusion.ai/app/devtools) to generate images from your own code and tools.
Good to know: everything you generate is saved automatically to your [My Gallery](https://retrodiffusion.ai/app/gallery), generation costs are charged from your account balance (shown in the top-right corner), and you can always recover a generation's exact settings with the Apply Settings arrow button above the canvas.

04 Describe it, approve it
The chat bar at the bottom of the canvas is the Generation Assistant. Describe what you want in plain words and it picks the model, style, size, and settings for you, shows a plan with the exact price, and runs it once you approve. It makes 2D pixel art and Low-Poly 3D models.

### How it works

- Ask.Type a request like "a knight sprite, then make it walk". Paste, drag, or attach images when you want it to work from your art.
- Review the plan.Every step shows its model, size, and price, plus the total. Nothing is charged until you approve.
- Approve, deny, or ask for changes.Replying with feedback gets you a revised plan.
- Watch it run.Steps go through the same queue as your own generations, and results appear in the chat, your history, and the canvas. The assistant checks every result and tells you honestly when something came out wrong.

### What it can do

- Multi-step work: a base sprite and then its animation, a set of matching items, variants of one image (seasons, palettes, outfits), and edits chained onto earlier results.
- Editing: the canvas edit tools, plus pulling single sprites out of an uploaded sheet.
- 3D, when you ask for it: build a Low-Poly model, revise it, animate it, or change one of its existing animations. Say "3D model" or "low poly"; otherwise it makes 2D art.
- The model on your canvas: when a 3D model is open, "animate this" or "make it blue" works on it directly. 3D results in the chat have an Open in 3D view button.
2D is the default. Requests are made as 2D pixel art unless you ask for 3D, so "animate my knight" animates the sprite, and "make a 3D model of my knight" builds a model.

### What it costs
Chatting is free. Approved plans bill at the normal price of each generation, edit, or 3D job, and failed steps are refunded automatically. After 20 messages without generating anything, chat pauses until something is generated. The same assistant is available to programs through the [assistant API](https://retrodiffusion.ai/app/guide/api#assistant) ($0.01 per message).

05 Getting what you asked for
Prompts describe the subject. The pixel art styling — outlines, shading, resolution feel — is handled by your model and art style choice, so you never need to write "pixel art" in a prompt.

### What works

- Subject first, then details: "A raven standing on a branch, with Appalachian forests and mountains in the background."
- Name concrete visual features: materials, colors, lighting, mood. "A hammer made of obsidian with a gold handle and a red gemstone."
- Match the style's intent: asset styles (Game Asset, Top Down Item, MC Item) work best when you describe a single object and mention a plain background; scene styles (Environments, Top Down Map) want a full scene description.
- Use the placeholder as a template. Every style shows an example prompt in the prompt box — it's written to match how that style was built.

### What to avoid

- Don't put sizes in the prompt ("32x32", "16 bit") — use the width and height settings instead. The prompt box will warn you if it spots this.
- Don't describe motion in image styles — for walking, attacking, or effects, switch to the Advanced Animations tab.
- Don't stack contradictions — "minimalist, extremely detailed" pulls the model in two directions.

### Handy prompt tools

- Expand Prompt (sparkles button) — turns a short idea into a detailed prompt, typed out live so you can watch and edit it after.
- Clear prompt (trash button) — empties the box; Ctrl+Z brings the old text back.
- Seeds — reuse the same seed with small prompt tweaks to iterate on a composition you like. Find a generation's seed in the canvas info menu (⋮).

07 Pixel art, now in 3D
The Low-Poly model builds real low-poly 3D models with hand-painted pixel-art textures. Every texture pixel is the same size on every face, so a model looks like pixel art from any angle, and it lives alongside your 2D work: same queue, same history, same canvas, same assistant.

### Making a model

- Pick Low Poly 3D in the model selector, then a style: Detailed (free-form shapes) or Blocky (boxes only, like a Minecraft model; boxes can be tilted for slopes like a windshield or roof, and it is best for Blockbench and Minecraft exports). Their Lite versions make simpler models for $0.10 at any size, great for props and drafts; editing or animating a Lite model is $0.08.
- Describe the object (up to 250 characters), add up to 4 references, or both. Images guide the look (several views of the same object work best). Drag a 3D model from your history into References to use that exact model, textures and all: it is placed where your prompt puts it (a table in a tavern) or adapted to fit.
- Optionally add a Palette (the same palette input as for images): the model is built with only its colors, and revisions and animations keep them.
- In Settings, choose a Size, the model's largest dimension in texture pixels. Auto reads your prompt (a coin is small, a castle is big); image-only requests use 64³. Simple requests ("a crate", "remove the text", "spin slowly") are built in a quicker mode automatically; anything detailed gets the full treatment. The price is the same either way.
- Generate. 3D models take a few minutes (large sizes can take 10 or more). They wait in the queue like any generation, and the finished model opens in the canvas.

### The 3D canvas

- Drag to orbit, right-drag to pan, and scroll to zoom. The toolbar has reset, turntable, perspective/orthographic, X / Y / Z view snaps (click again for the opposite side), bones,wireframe, and copy (a square image of the current view, on your clipboard for sharing).
- Switch between the 3D view and the texture atlas, the flat image every face is painted from.
- Export for… Godot, Unity, Unreal, the web, or Blender (.glb), Blockbench (.bbmodel), other 3D apps (.obj), a Minecraft Java resource pack, the atlas, a turntable sprite sheet, or any animation as a GIF, sprite sheet, or high-res MP4 video. The .glb and Blockbench files carry every animation, ready to play in the engine.
- Re-rig (in the tool sidebar, on rigged versions) rebuilds the skeleton: move a pivot, add bones, or leave the prompt empty for a fresh rig. Animations whose bones stay keep working.
- Split (in the tool sidebar) breaks the model into separate models: a desk with things on it becomes the desk, the candle, each book, and so on, each its own history item facing the front, with its own textures and every animation it was in. Leave the prompt empty to split off every object, or say how ("only the books", "each drawer too").
- Color Reducer, Palette Converter and Color Style Transfer (in the tool sidebar, the same tools as on the image canvas) recolor the model's textures: reduce the number of colors, convert to a palette, or take another image's color style. The result is a new version, and later revisions and animations keep the colors.

### Revising and animating

- Revise (left toolbar): describe what should change. The result is saved as a new version, and you can switch between versions at the bottom of the canvas.
- Animate: describe a motion ("a bouncy walk cycle", "swing the sword"). It is added to the version you're viewing, and the first animation adds a skeleton for free. Every animation plays as a live preview in the list on the right of the canvas; click one to view it.
- Changing an animation: pick it in the animation list on the right, then open Revise. The tool switches to animation editing (the banner says which animation), and only the motion changes.

09 Every knob explained
Settings appear and disappear based on the selected style — you only see what applies. Here is the full list.

SettingWhat it does
Width / HeightOutput size in pixels, within the style's limits (16–384 px depending on style). This is the real pixel resolution — downloads can be upscaled, but the art is made at this size. Some styles snap to multiples or fix the aspect ratio; a Snap Size button appears for styles that can detect the pixel size of your input image.

11 Your art style, on demand
My Styles lets you build a custom style from your own artwork. It works with reference images — you supply examples, and generations follow their look. No training wait, no extra fee to create a style; you only pay for the generations you run with it.

### Creating a style

- Go to [My Styles](https://retrodiffusion.ai/app/my-styles) and click Create New Style.
- Choose a template (RD Pro is the standard reference-image style) and give the style a name.
- Upload 1–4 reference images that clearly show the style you want — consistent examples work far better than a mixed bag.
- Optionally add a Prompt Modifier — extra text merged into every prompt. It must contain {prompt} where your per-generation prompt should be inserted.
- Optionally force a color palette so every generation sticks to your colors.
- Use Test Style inside the editor to run trial generations (charged like normal generations, results are temporary previews), tweak, and save.

### Using and sharing

- Your styles appear under the My Styles tab in the generator's model panel — select one and generate as usual, with up to 9 reference images per generation.
- Choose who can use each style: Private (only you), Link (anyone with the link, kept out of Explore; make a new link any time to turn the old one off) or Public (listed in [Explore](https://retrodiffusion.ai/app/explore/styles) with a cover image).
- Styles you add from Explore or a link stay connected to the original and pick up its creator's updates. Change anything and save, and it becomes your own remix, credited back to the original.
Best results come from reference images that share one consistent resolution and technique. If your references mix 16px icons with 256px scenes, the style will be muddled.

13 Automate everything
Retro Diffusion is available over a simple HTTP API — generate images, run edit tools, repair softened pixel art, and manage custom styles from scripts, game engines, or build pipelines.

### 1. Get an API key

- Go to [Developer Tools](https://retrodiffusion.ai/app/devtools) and click the + button under API Keys. You can have up to 5 keys.
- The full key (starting with rdpk-) is shown once at creation — store it somewhere safe. The page only ever shows the prefix afterwards.
- API usage spends the same account balance as the website. Revoke a key any time from the same page.

### 2. Generate an image
Send a POST request to the inferences endpoint with your key in the X-RD-Token header:
generate.py
import base64
import time
import requests

url = "https://api.retrodiffusion.ai/v2/inferences"
headers = {"X-RD-Token": "YOUR_API_KEY"}
payload = {
 "prompt": "A wizard's tower on a floating island, waterfalls",
 "prompt_style": "rd_fast__default",
 "width": 128,
 "height": 128,
 "num_images": 1,
}

start = requests.post(url, headers=headers, json=payload)
start.raise_for_status()
task_id = start.json()["task_id"]

while True:
 response = requests.get(f"{url}/tasks/{task_id}", headers=headers)
 response.raise_for_status()
 task = response.json()
 if task["status"] in ("pending", "running"):
 time.sleep(2)
 continue
 if task["status"] == "failed":
 error = task["error"]
 raise RuntimeError(f"{error['code']} (request {error['request_id']})")
 data = task["result"]
 break

for i, image in enumerate(data["base64_images"]):
 with open(f"output_{i}.png", "wb") as f:
 f.write(base64.b64decode(image))

print(f"Remaining balance: ${data['remaining_balance']}")
