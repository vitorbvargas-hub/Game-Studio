# Orientação obrigatória para o agente

Não basta assistir aos vídeos superficialmente. Para cada jogo:

1. Registrar os vídeos assistidos, links, duração e trechos relevantes.
2. Identificar os sistemas de gameplay e documentar como funcionam.
3. Registrar cada Digimon observado e suas evoluções.
4. Separar as informações por jogo. Não misturar requisitos de títulos diferentes.
5. Registrar timestamps de evolução, treinamento, combate, exploração, interface e progressão.
6. Priorizar vídeos longos e séries completas, complementando com vídeos específicos de mecânicas.

## Foco especial: evolução

Para cada Digimon, construir uma ficha com:

- Digimon de origem e estágio.
- Todas as evoluções possíveis.
- Requisitos individuais para cada caminho.
- Nível, atributos, personalidade, treinamento e condições especiais, quando aplicáveis.
- Itens, missões, vínculo, vitórias e outros requisitos, quando aplicáveis.
- Evoluções alternativas, ramificações e regressões, se existirem.
- Diferenças entre os jogos.
- Fonte e timestamp que comprovem cada informação.

**Entrega esperada:** uma base estruturada de Digimon e árvores evolutivas, com um grafo visual por Digimon, e uma comparação entre os jogos. Não inventar requisitos quando não houver evidência: marcar como desconhecido e pesquisar.
