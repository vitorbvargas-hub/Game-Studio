
# DIGIMON-FIRST ASSET DISCOVERY

REGRA PRINCIPAL:

O Game Studio deve priorizar fontes específicas de Digimon.

Não substituir automaticamente um Digimon por um monstro genérico encontrado em marketplaces.

## FONTES PRIORITÁRIAS

1. https://dim.digitallink.games/resources?category=digimon
2. https://github.com/E-M-B-E-R/digimon-world-ds-dawn-dusk-animated-sprites
3. https://github.com/kaisadilla/digimon-sprite-collection
4. https://aderekart.github.io/
5. https://github.com/netraular/DigimonWorldSpriteManager
6. https://github.com/kongtaehun/digimon-assets-VB
7. https://cinzadeneve.itch.io/

## ORDEM DE PESQUISA

Para cada criatura:

1. Pesquisar seu sprite oficial ou fan-made.
2. Pesquisar versões de Digimon World DS.
3. Pesquisar versões Dawn/Dusk.
4. Pesquisar sprites animados.
5. Pesquisar spritesheets comunitários.
6. Verificar outras fontes Digimon.
7. Avaliar possibilidade de adaptação.
8. Somente depois considerar criação original.

## IDENTIDADE VISUAL

Priorizar sprites que mantenham:
- Identidade reconhecível do Digimon.
- Estética pixel art.
- Proporções consistentes.
- Perspectiva compatível com o mapa.
- Animações adequadas ao idle MMORPG.

Não utilizar criaturas genéricas como substitutas de Digimons.

## TRATAMENTO DE LACUNAS

Se encontrar um Digimon sem animação walk:
- Não substituir por outra criatura.
- Procurar outras versões do mesmo Digimon.
- Avaliar produção de animação original autorizada.

Se não encontrar sprites:
- Registrar a ausência.
- Criar uma proposta de criatura original inspirada
  apenas em características gerais, sem copiar personagens protegidos.
- Não apresentar a criação como Digimon oficial.

## LICENCIAMENTO

Cada arquivo deve ter origem e licença verificadas.

Separar:
- Referências.
- Uso em protótipos privados.
- Assets licenciados.
- Assets originais.

Nunca presumir autorização comercial.

## RESULTADO

Criar um Digimon Asset Index com:
- Nome.
- Estágio evolutivo.
- Fonte.
- Sprite disponível.
- Idle disponível.
- Walk disponível.
- Attack disponível.
- Sleep disponível.
- Licença.
- Qualidade.
- Status.

Objetivo: construir primeiro um inventário completo
das fontes específicas de Digimon antes de produzir
ou procurar criaturas genéricas.
