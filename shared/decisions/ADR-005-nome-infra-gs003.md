# ADR-005 — Nome do estúdio, infraestrutura e abertura do GS-003

Data: 2026-11-08 · Decisor: Vitor Vargas

1. **Nome do estúdio: Nação Games.** As outras 3 propostas foram descartadas.
2. **Infraestrutura aprovada como padrão:** GitHub + Cloudflare para hospedagem; Supabase (região São Paulo) só quando houver login ou dados pessoais; Vercel fora. Criar cada conta e assumir cada custo recorrente continua exigindo aprovação pontual.
3. **GS-003 aberto (DISCOVERY):** idle de coleção de monstros a partir das referências do fundador. Criaturas, nomes e arte originais (sem IP de terceiros).
4. **Busca web:** o provider Gemini está sem cota. Os providers gratuitos (DuckDuckGo, Parallel) exigem OpenClaw ≥ 2026.11.2, e a versão instalada é a 2026.9.8. A decisão sobre atualizar fica com o fundador.
